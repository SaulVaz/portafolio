SoundMatch — Sistema de Recomendación de Música — Proyecto personal

App web que conecta tu cuenta de Spotify y usa Machine Learning para recomendarte canciones nuevas basadas en tu historial real. Integré Last.fm para enriquecer artistas con géneros y mood tags reales, construí un modelo de similitud de coseno con feature engineering propio, añadí explicabilidad visual y lo deployé completamente en producción con Docker + Render (backend) y Vercel (frontend).

// Por qué estas tecnologías

React + TypeScript con Recharts para las gráficas de explicabilidad.Docker para containerizar el backend y deployarlo en Render — esto garantiza que el entorno de producción sea idéntico al de desarrollo y hace el deploy reproducible en cualquier plataforma.
